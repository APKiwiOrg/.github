# Branding

Source files for the APKiwiOrg mark, a glitch-scanline kiwi on `#0b0b12`.

| File | What it is |
|---|---|
| `apkiwiorg-logo-glitch.svg` | Vector master, 512x512, self-contained (no external refs or fonts). Edit this one. |
| `apkiwiorg-logo-glitch.png` | 1024x1024 raster export. This is what the org avatar was uploaded from. |

The org avatar is not served from here, GitHub keeps its own copy, so re-uploading the PNG in
org settings is a manual step after any change. The profile README hotlinks the PNG at
`https://raw.githubusercontent.com/APKiwiOrg/.github/main/branding/apkiwiorg-logo-glitch.png`,
so keep that path stable.
