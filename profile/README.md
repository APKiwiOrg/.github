# APKiwiOrg

Indie games on our own engine.

## KhaozEngine

[KhaozEngine](https://github.com/APKiwiOrg/KhaozEngine) is the in-house tech behind everything here, and its source is public (source-available, not open source). It's a .NET 10 2D/3D engine with its own Metal, Vulkan and Direct3D 11 renderers, plus GUI, particles, ECS, audio, physics and an authoritative multiplayer stack built to scale from solo play to a sharded MMO world.

## Games

| Game | What it is |
|---|---|
| **Grimhollow** | A low-poly, OSRS-style 3D MMO |
| **Ruinborne** | A 3D MMO set in a ruined world |
| **Hardpoint** | A real-time 3D tower defense with a pixel-retro look |
| **Nullwake** | A 2D idle mining game set in deep space |
| **SpaceGame** | A deterministic 2.5D sci-fi roguelike with online co-op |

The games are in private repos while we build. More to show soon.
